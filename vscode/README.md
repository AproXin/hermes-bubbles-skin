# Hermes Bubbles Blue Glass Theme

A modern, high-contrast dark blue glass theme inspired by the Hermes AI desktop agent bubbles skin.

## Features
- **Deep Obsidian Blue Base**: `#092038` background with glowing cyan and soft blue accents (`#60a5fa`, `#93c5fd`).
- **Carefully Tuned Contrast**: High legibility across syntax highlighting and workbench surfaces.
- **Terminal Integration**: Optimized ANSI palette matching deep navy backgrounds.

## Installation
Install from the VS Code Marketplace or in Hermes Desktop via **Settings → Appearance → Install theme from Marketplace**.
