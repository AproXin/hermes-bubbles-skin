## 一、这次修了什么

### ① 出错时不再「悄悄失败」，控制台会明确告诉你

**以前**：插件内部有好几道工序，某一道出错时它会把错误默默记住，**什么都不显示**。于是你会看到「某个小面板没出来」，而日志里干干净净，连报错都没有。

**现在**：哪道工序出错，控制台就打印一行错误，写清是哪一步、错在哪。

> 提交 `72fe4f5`、`ce4b15a`

### ② 堵住了一个 HTML 注入漏洞

**以前**：聊天内容预览卡片是「用字符串拼 HTML」再塞进页面的，而拼接时的转义函数**漏掉了单引号**。这类写法在桌面客户端里属于高风险做法。

**现在**：预览卡片不再拼字符串，改为用正规方式**逐个创建页面元素**、把文字当纯文本放进去——从根子上消除了这类注入可能。

> 提交 `663e400`、`8bf6a23`、`7ba13fc`

### ③ 文档与实际代码对齐

文档里有几处自相矛盾——一处写「54 个测试套件」、另一处写「55 个」；还有一条注释引用了**根本不存在的章节**（写着「见第 9 节」，但全文只有 8 节）。现已改齐。

> 提交 `cb44132`

## 二、顺带一起进来的改进

这几项不在最初的清单里，但已经做完并一起发布：

| 改进 | 说明 |
|------|------|
| **CI 质检不再「假装通过」** | 以前远程自动检查会**跳过 56% 的关键测试**（尤其是真正打开浏览器量尺寸、量颜色那批），却仍显示「通过」。现在补装了浏览器，**跳过即判失败**，「放行门槛」也被废除。 |
| **部署前自动备份 + 一键回滚** | 以前往本机安装插件是「直接覆盖」，装坏了没法退。现在每次部署前自动备份，并新增 `--rollback` 一键还原。 |
| **不再「绑架」其他皮肤** | 以前只要装了这个插件，**不管切到哪个皮肤**它都强行生效。现在会先确认当前用的确实是 Bubbles 皮肤，不是就自动让开。 |
| **拆分了一个巨型函数** | 一个 244 行、复杂到没人敢碰的核心函数被拆成小块。**内部改造，界面表现不变。** |

> 提交 `a16d147`（CI）、`fbbe3b6`（备份回滚）、`323a0f2`（皮肤作用域），以及函数拆分的 10 次提交

## 三、怎么升级（三步）

```bash
# 第 1 步：进入仓库根目录
cd <仓库根目录>

# 第 2 步：拉取最新代码
git pull

# 第 3 步：装配并部署（插件 + 皮肤一起装）
node scripts/sync.js
```

- 第 3 步会打印 `customCSS <当前>/<上限> 字符`。**没报错、退出码 0 就算成功。**
- 只想装插件、不动皮肤：`node scripts/sync.js --no-skin`
- 部署号只由源码内容决定，多跑几次结果一样。
- ⚠️ **部署完成后必须 `Cmd + Q` 完全退出再重开 Hermes**，插件才会真正生效。

升级前想先确认代码没问题（可选，约 1 分钟）：

```bash
node scripts/run-tests.js
# 期望：57 passed / 0 failed / 0 skipped（套件总数以该命令实测输出为准）
```

## 四、如果有问题，怎么回滚

```bash
cd <仓库根目录>
node scripts/sync.js --rollback
```

- 用的是**部署时自动生成的备份**（`~/.hermes/desktop-plugins/hermes-bubbles-skin/.backup/`，按时间戳分目录）。
- **最多保留 5 份**，更旧的自动清理。
- 从未部署过时它会**明确拒绝并说明原因**，不会乱动文件。
- **回滚后同样需要 `Cmd + Q` 重启**才生效。

**手动兜底**：备份目录里每个时间戳文件夹都完整保存了当时的 `plugin.js` / `plugin.yaml` / `bubbles.yaml`，手工拷回对应位置即可。

**想确认当前装的是哪个版本**：

```bash
md5 ~/.hermes/desktop-plugins/hermes-bubbles-skin/plugin.js
```

与仓库根目录 `plugin.js` 的指纹比对（`md5 plugin.js`）：`sync` 部署的就是同一份内容，一致即说明装的是干净版本、没人手改过。

## 五、诚实声明（限制与副作用）

1. **`escapeHtml` 这个函数现在实际上「没人用了」。** 改成安全 DOM 构造后，它在生产代码里已无调用点，只剩定义；但**暂时删不掉**——有测试套件会提取它做检查，删了测试就挂。属本次留下的已知技术债。
2. **本次不解决「宿主改版导致失效」的问题。** 插件依赖宿主的一些内部类名与图标名识别界面元素，宿主升级后这些名字可能变化，导致部分增强功能静默失效。项目里有专门的「选择器漂移」测试在盯着，但**本次没有根治**。
3. **界面外观没有变化。** 本次是内部加固，**不要期待视觉上的不同**。
4. **性能相关的已知问题未修。** 插件样式表里有 780 处 `!important`，某些流程存在「强制重排」，长会话下可能卡顿。**本次未处理**。
5. **测试通过数**：**57 passed / 0 failed / 0 skipped**。套件总数已从 55 增长到 57（新增「备份回滚」与「皮肤作用域」两套）；**以 `node scripts/run-tests.js` 的输出为准**。
